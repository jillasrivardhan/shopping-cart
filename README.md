# 🛒 Shopping Cart Website

# this is just a beginner shopping cart just with a frontend ui and also note no javascript involved

A modern, responsive shopping cart website built using **HTML** and **CSS**. This project demonstrates the fundamentals of frontend web development by creating a multi-page e-commerce interface with a clean user experience and organized layout.

The project is designed for learning purposes and showcases essential concepts involved in building an online shopping website.

---

## 📌 Project Overview

This project simulates the frontend of an e-commerce website, allowing users to navigate through different pages such as Home, Login, Booking, and Shopping Cart.

It focuses on creating an attractive and user-friendly interface while practicing responsive layouts, styling techniques, and website navigation.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/jillasrivardhan/shopping-cart.git
```

### Navigate to the project

```bash
cd shopping-cart
```

### Run the project

Simply open **home.html** in your preferred web browser.

No additional installation or dependencies are required.
